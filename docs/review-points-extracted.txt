9. Setting up accounts &amp; connecting a custom domain (Firebase)
Since this project runs on Firebase, please follow the steps below.
9.1 Creating your own account
Do not reuse a personal or client Google account for development work. Create (or use) your own Google account, and sign in to the Firebase console at https://console.firebase.google.com with it.
Ask the client to add this Google account as a member on the existing Firebase project (Firebase console → Project settings → &quot;Users and permissions&quot; → Add member), with the role that matches the work you need to do (Editor for most development tasks; Owner only if strictly necessary).
Once added, confirm you can see the project in your own Firebase console and that you can access the products already in use on this project (e.g. Hosting, Authentication, Firestore) — check with the client which products are active for this project.
Do the same for Vercel if you also need access there: ask to be invited as a member of the Vercel team/project (Vercel dashboard → Project → Settings → Members).
9.2 Connecting a custom domain
In the Firebase console, go to Hosting → &quot;Add custom domain&quot;, and enter the domain that should point to the portal.
Firebase will provide a TXT record to verify domain ownership. Add this record at the domain registrar (DNS settings) for that domain.
Once verification succeeds, Firebase provides one or more A records (or a similar hosting record) to point the domain to Firebase Hosting. Add these records at the registrar as well.
Allow time for DNS propagation (this can take anywhere from a few minutes up to 24–48 hours) and for Firebase to automatically issue an SSL certificate for the domain.
Note: the portal currently also runs on Vercel (hnb-portal.vercel.app). If the final hosting platform is Vercel rather than Firebase, the domain must instead be added under Vercel → Project → Settings → Domains, and the DNS records at the registrar should point to Vercel (typically a CNAME to cname.vercel-dns.com, or the A record Vercel provides) rather than to Firebase. Please confirm with the client which platform will be the final production host before configuring DNS, to avoid configuring both and causing conflicts.
